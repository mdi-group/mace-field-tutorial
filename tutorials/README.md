# MACEField tutorials

The MACEField-only course is maintained in the [tutorial guide](macefield/README.md). The notebooks are independent and use the MACE-Field package's `main` branch.

Start with the BaTiO₃ sequence, continue with the α-quartz SiO₂ response and spectroscopy lessons, or open the standalone foundation-model lesson directly. Every lesson has its own Colab link and required input assets.
