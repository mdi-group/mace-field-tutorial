# Tutorial checkpoints

Model checkpoints are generated by the training scripts and are not bundled in this directory. Notebook training runs write checkpoints here; in Colab they remain in the temporary runtime unless downloaded.

| Notebook key | Generated checkpoint | Training script | Dataset |
| --- | --- | --- | --- |
| `dipole` | `tutorials/models/atomicdipoles/AtomicDipolesMACE-toy.model` | `tutorials/scripts/train_atomicdipoles.sh` | `atomicdipoles_water_{train,valid}.extxyz` |
| `magnetic` | `tutorials/models/magnetic/MagneticMACE-toy.model` | `tutorials/scripts/train_magnetic.sh` | `magnetic_fe2_{train,valid}.extxyz` |
| `les` | `tutorials/models/maceles/MACELES-toy.model` | `tutorials/scripts/train_maceles.sh` | `maceles_water_dimer_{train,valid}.extxyz` |
| `short_range` | `tutorials/models/maceles_short_range/MACELES-short-range-control.model` | `tutorials/scripts/train_maceles_short_range.sh` | Same water-dimer files as LES |
| `field` | `tutorials/macefield/runs/bto_macefield_training/MACEField-BaTiO3-reference_run-23.model` | `tutorials/macefield/scripts/train_macefield.sh` | Copied BaTiO₃ reference split |

The non-BTO extension labs use small analytic teaching labels to exercise software interfaces. Their fitted checkpoints are demonstrations, not accuracy benchmarks. Regenerate those datasets with `python tutorials/scripts/prepare_teaching_data.py` from this repository root.
